# convert - Convert packages to project structure

Convert packages to project structure.


## Synopsis

```bash
clio convert [OPTIONS]
```


## Description

Converts package folders into project layout used by clio for source-based development.


## Examples

```bash
clio convert -p ./Pkg MyPackage
clio convert -p ./Pkg
```
