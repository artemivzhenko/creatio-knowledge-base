# User-task tools

Scripts that read and change user tasks as **package files** (`Schemas/<Task>/metadata.json`,
`<Task>.cs`, `Resources/<Task>.ProcessUserTask/`). Pure Python standard library.

| File | What it does |
| --- | --- |
| `usertask.py` | CLI: inspect, validate, method, new, add-param, remove-param, rename-param, set-caption, set-source |
| `../creatio_schemas/usertask/schema.py` | `UserTaskSchema`: the library the CLI and the describe layer use |
| `tests/test_usertask_tools.py` | checks on a real task with generic names |

## How a task is stored

- `FJ1`: the parameters, the same `ProcessSchemaParameter` a process has (`L1` type, `L12`
  direction, `L6` required, `L16` referenced object); the platform generates a property per
  parameter in its half of the partial class.
- `FK7` IsUserTask, `FK16` HasUserDefinedCode, `FK12` the colour of the element in the designer;
  `properties.json` carries `IsInteractive` (the task waits for a user).
- `<Task>.cs`: `public partial class <Task>` in `Terrasoft.Core.Process.Configuration` overriding
  `InternalExecute` (the work), `CompleteExecuting`, `CancelExecuting`, `GetExecutionData`,
  `GetNotificationData`.
- Resources: `Caption`, `Parameters.<Name>.Caption` and the designer icons as image items
  (kept byte for byte - the Resources class preserves non-string items).
- `Autogenerated/Src/<Task>Schema.<Pkg>.cs`: the platform's half of the partial class (the base
  `ProcessUserTask`, one property per parameter, their (de)serialisation). The environment
  compiles it from the metadata; a clio workspace build needs it as a file, so the toolkit writes
  it on every save when the package has a `Files/*.csproj` and every parameter type is one of
  Guid, Lookup, text, Integer, Boolean, date/time, Float*, Money. Other types: the platform's
  file, if any, is left as it is.

```bash
python usertask.py inspect packages/UsrPkg UsrNotify_UserTask
python usertask.py new packages/UsrPkg UsrNotify_UserTask --caption "Notify owner" --param RecordId:Guid:In:required --param Sent:Boolean:Out
python usertask.py add-param packages/UsrPkg UsrNotify_UserTask Note Text --caption "Note"
python usertask.py set-source packages/UsrPkg UsrNotify_UserTask ./UsrNotify_UserTask.cs
python describe.py item packages/UsrPkg UsrNotify_UserTask "method InternalExecute"
```

Validation refuses duplicate parameters, an unknown data value type and a `.cs` without the
partial class; a missing caption or a missing `InternalExecute` override is a warning.

## Verified

Files only: the two real tasks of a dev-kit package round-trip byte for byte, icons included. On
the test environment (8.2.3): a task made by `new` (a required Guid in, a Text out, the C#
skeleton) was pushed with `clio push-pkg`, the configuration compiled with 0 errors and the schema
is in `SysSchema` under `ProcessUserTaskSchemaManager`.
